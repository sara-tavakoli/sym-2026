# SYM 2026

## Getting started in VS Code

1. Open VS Code.
2. Press `Cmd+Shift+P` (macOS) or `Ctrl+Shift+P` (Windows/Linux) and run **Git: Clone**.
3. Paste the repository URL:
   ```
   https://github.com/sara-tavakoli/sym-2026.git
   ```
4. Choose a folder to save it in, then click **Open** when prompted.

Or from a terminal:

```bash
git clone https://github.com/sara-tavakoli/sym-2026.git
cd sym-2026
code .
```

> This repository is private — you need to be added as a collaborator before you can clone it.
